Forest-loss review workbench

Research prototype · four Sri Lankan protected-forest sites · loss years 2019–2024
The tool suggests a driver for each loss event from satellite evidence. A suggestion is a probability-based attribution, not a legal or enforcement finding. The analysis is retrospective, not real time.
How to use this page
  1. Pick an event on the left. Use the filters to narrow the list (by call, thin evidence, review state or site).
  2. Read the tool's call, then the chart. Each dot is one clear satellite observation. The shaded bands are the only windows the call may use.
  3. Check the dates against the chart. If a patch carries a "rule-dated" notice, a program guessed the dates and nobody has checked them.
  4. Use "Open in Google Maps (satellite)" to look at the ground. That imagery is not from the event date, so use it for context only.
  5. Record your own view: agree, override or uncertain, with a note. Then save. "Export my reviews" downloads your answers as a CSV.
  6. Remember: a call is a probability-based suggestion, not a finding about who cleared the forest.
