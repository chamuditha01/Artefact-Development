## Labelling order (method)

Protocol §8 requires a randomized order, not confirmation-queue order, so
labelling isn't biased by whatever sequence REF events were originally
screened/confirmed in.

- Method: Python `random.seed(44)`; `random.shuffle()` on the 30 `queue_id`
  values from `REF_30_confirmed_events.csv`.
- Recorded here (per issues.md A15's own point - a method only counts as
  primary/reproducible if it's written down, not just remembered) so this is
  reproducible and auditable later.
